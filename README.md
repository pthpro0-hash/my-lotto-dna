# MY LOTTO DNA

날짜·날씨·사주·성향 등 7가지 신호로 매일 만드는 '나만의 로또 숫자'와 1~최신 회차 실제 통계를 보여주는 웹앱(PWA)입니다.

- 재미로 보는 콘텐츠이며 당첨 확률과 무관합니다. 어떤 조합이든 1등 확률은 1/8,145,060입니다.
- 만 19세 이상만 이용할 수 있습니다. 복권 판매·구매 대행을 하지 않습니다.

## 구조
- `src/lib/fortune.ts` 운세 숫자 엔진(결정론, 브라우저에서 실행)
- `src/lib/qr.ts` 로또 용지 QR 해석(기기 안에서만 실행, 원문은 서버로 보내지 않음)
- `src/api.ts` Supabase 연결 (publishable 키만 사용, 데이터 보호는 서버 RLS)
- 배포: `main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포
